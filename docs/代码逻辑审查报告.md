## 四、可以更严谨的写法（3 处，非错误）

这几处**结果都是对的**，只是写法上可以更讲究。改不改都不影响运行，留给以后学更多语法时回看。

### 1. `lesson06/ArrayPractice2.java` —— 求最大值时多比了一次

```java
int max = arr[0];                              // 先假设第一个元素最大
for (int i = 0; i < arr.length; i++) {         // 从 0 开始，把自己又比了一次
    if (arr[i] > max) {
        max = arr[i];
    }
}
```

- **为什么没错**：`i = 0` 时是拿 `arr[0]` 和自己比，`arr[0] > arr[0]` 永远为假，`max` 不会被改坏，结果照样正确。
- **更讲究的写法**：从 `i = 1` 开始，跳过「自己跟自己比」这一次。
- **顺带一提**：`if` 里的大括号其实可以不写（只有一行），但写上是好习惯 —— 以后再往里加一行就不会出错。

### 2. `day02/LeapYear2.java` —— 判断闰年时 `&&` 和 `||` 混在一起

```java
return year % 4 == 0 && year % 100 != 0 || year % 400 == 0;
```

- **为什么没错**：Java 里 `&&` 的优先级**高于** `||`，所以这行实际被理解成
  `(year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)`，正好是闰年的正确判断。
- **更讲究的写法**：主动加上括号
  `return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);`
  不是给电脑看，是给人看 —— 别人（包括几个月后的自己）一眼就懂，不用去想优先级。
- **这是好习惯**：混用 `&&` `||` 时一律加括号，是业界的通行做法。
